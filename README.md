# zcode-plus

这是我自己魔改 ZCode 客户端时搓出来的一套轻量补丁。

官方客户端写代码挺顺手，但日常用起来有些地方实在让人难受：一上来 token 疯狂缩水、界面死黑刺眼、还有一堆没必要的后台遥测。于是我把它的本地文件扒开做了点外科手术，整理成了这个一键打补丁工具。


## 为什么搞这个？

前几天我调试时抓了下网络日志（`~/.zcode/cli/rollout/model-io-*.jsonl`），结果大吃一惊：我连一句需求都还没发，客户端发给模型的初始上下文就已经干到了 **36,000+ tokens**。

当时我就懵了，顺着调用链排查才发现：
1. 客户端默认在会话里塞了 32 个系统工具，光工具声明就吃了 34,000+ tokens（占了 94% 以上）。
2. 最离谱的是 `CreateWorkflow` 和 `SaveWorkflow`，这两个平时敲代码几乎用不到的工具，描述里居然硬塞了一整套 2 万字符的 TypeScript SDK 说明文档……单它俩就吃掉了将近 **2.3 万 tokens**！
3. 还有定时任务（Cron）和离峰任务（Off-Peak），写代码时根本用不上，又吞了 3,500 tokens。
4. 另外还有长篇大论的安全免责声明和教 AI 怎么写作文的指南。

合着我每开一个新会话，API 额度和上下文窗口全拿去给大模型背诵工作流手册了。不仅烧钱，还把首字响应（TTFT）拖得巨慢。


## 我改了些什么？

### 1. Token 大手术：36K -> 7K (-78%) [重点]

我在 `resources/glm/zcode.cjs` 的 `toContracts` 里加了个过滤，把 16 个平时敲代码根本用不到的工具全剔除了（Workflow 全家桶、Cron 全家桶、Off-Peak 等）。顺便把 `EnterPlanMode`、`ExitPlanMode` 和 `AskUserQuestion` 里那些老长的小作文脱水精简。

* **核心编码工具我一个没动**：`Bash`、`Read`、`Write`、`Edit`、`Agent`、`SendMessage`、`AskUserQuestion`、计划模式全部 100% 完好。
* **改完效果**：初始会话从 36,000+ tokens 直接砍到 7,000 ~ 8,000 左右，一次对话净省 2.8 万 tokens。首字吐出来的速度肉眼可见地快了一截。

### 2. 关于系统提示词（打补丁时的 y/N 选项）

我在补丁脚本里加了个交互提示，让你自己决定要不要动系统提示词：
* **如果你用的是 GLM 官方订阅 / 官方套餐**：直接按回车（选 **N**）。官方模型针对原本那套提示词做了深度微调和 Prompt Cache 缓存，不动提示词能保证缓存命中和输出稳定。不用担心，上面的 16 个冗余工具依然会被剔除，一样能省下 2.6W+ tokens。
* **如果你跟我一样用第三方模型 / 自定义 API（Claude、DeepSeek、GPT 等）**：输入 **Y**。我会把原本那些冗长的安防免责和话痨沟通规范换掉，换成我整理的「深模块设计」和「决策树质询」工程准则（在 `docs/engineering-standards.md`），让模型干活更像个严谨的资深工程师。

### 3. 看得见真实的 TTFT 和吐字速度

官方自带的计时太粗了，多步 Agent 调用时根本分不清哪个阶段卡了多久。我在每条助手消息底部加了行紧凑的单行 Serif 指标条：
`⚡ TTFT: 1.15s · 68.5 t/s · 1240 tok (思考 1180 + 回复 60) · 18.2s`
精确记录真实的首次响应时间（TTFT），排除掉工具本地读写磁盘的耗时，只算模型纯生成的吞吐速度。

### 4. 换掉死黑界面，顺眼多了

我加了两套自己顺眼的主题，在「设置 -> 外观」里就能直接切：
* **Monokai 暖黑**：经典橄榄暗灰底（#272822），不反光不瞎眼。
* **Solarized 浅色**：温润的暖米黄底（#fdf6e3），白天看很舒服。
* 字体顺便换成了思源黑体（`Noto Sans`），代码块依然保留原本的等宽字体。

### 5. 把后台遥测给掐了

官方在客户端里埋了阿里云 ARMS RUM、OpenTelemetry APM 链路监控，还有每次上报设备指纹的 `/api/v1/event/report`。我全给熔断或重定向到本地了。滑块人机验证保留了，不会影响正常登录和风控。


## 怎么用？

很简单，不需要编译什么复杂玩意儿：

1. **先完全关掉 ZCode 客户端**（避免文件被占用）。
2. 双击运行 `apply_patch.bat`（或者在终端跑 `node auto_patch.js`）。
3. 弹出来问你改不改提示词：GLM 官方订阅直接回车，第三方 API 用户输 Y。
4. 跑完重新打开 ZCode，搞定。

想彻底还原回官方原版？双击运行 `restore_backup.bat`，原版备份秒级覆盖回来。


## 文件说明

* `auto_patch.js`：核心补丁脚本，自动解包 asar、打补丁、改 zcode.cjs、重新打包。
* `apply_patch.bat`：Windows 双击一键执行。
* `restore_backup.bat`：一键还原官方纯净版。
* `docs/engineering-standards.md`：注入给模型的深模块与决策树工程准则。
* `README.md`：你正在读的文件。
