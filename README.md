
ZCode 客户端写代码很顺手，但原本有些地方太笨拙啦喵！一开会话就悄悄塞了 3.6 万 token，界面黑乎乎的刺眼，还藏着不少后台遥测……
于是给它动了个轻巧的外科手术，整理成了这个双击即用的一键补丁包哦~ ٩(๑>◡<๑)۶


## ✨ 做了哪些优化喵？

### 1. ⚡ Token 大瘦身：36K 骤降到 7K (-78%) [重头戏！]

原本开局一句话没发就吃掉 **36,000+ Tokens**（后台偷偷塞了 32 个系统工具，光一个用不上的工作流手册就占了 2.3 万 token 喵！）。
给它做了精准轻量裁剪：
* **过滤 16 个冗余工具**：彻底剥离平时写代码根本用不上的 Workflow 全家桶、Cron 定时任务、Off-Peak 离峰等；
* **核心工具描述脱水精简**：压缩 `EnterPlanMode`、`ExitPlanMode`、`AskUserQuestion` 的冗长说明；
* **核心写代码工具 100% 完整保留**：`Bash`、`Read`、`Write`、`Edit`、`Agent`、`SendMessage`、`AskUserQuestion`、计划模式全都在，开发调试丝毫不受影响喵；
* **单次立省 2.8 万 Tokens**：初始会话直接降到 **7,000 ~ 8,000 Tokens**，首字吐出来飞快，再也不用心疼额度啦 ฅ^•ﻌ•^ฅ！

### 2. ❓ 交互式提示词选择（打补丁时的 y/N 选项）

运行补丁时会弹出贴心的一行询问，按需求选就好啦：
* **GLM 官方订阅用户**：直接按回车（选 **N**）喵！保持原版提示词，官方模型 Prompt Cache 缓存不掉队，输出最稳，工具瘦身依然全部享受；
* **第三方模型 / API 用户 (Claude/DeepSeek/GPT等)**：输入 **Y** 喵！精简冗长安防长文，并注入「深模块设计 & 决策树」工程准则（[docs/engineering-standards.md](docs/engineering-standards.md)），写代码更聪明~ (｡•̀ᴗ-)✧

### 3. ⚡ 消息底部常驻真实 TTFT 与生成速度

在每条助手消息底部加了行精致小巧的指标条：
`⚡ TTFT: 1.15s · 68.5 t/s · 1240 tok (思考 1180 + 回复 60) · 18.2s`
精确记录真正的首次响应时延（TTFT）与每秒吐字速率，多步 Agent 协同也不迷路喵~

### 4. 🎨 两套护眼主题 + 思源黑体

告别刺眼的死黑色，在「设置 -> 外观」随时切换：
* **Monokai 暖黑**：经典暗橄榄灰底（#272822），护眼久看不累；
* **Solarized 浅色**：温润 Base3 暖米黄底（#fdf6e3），白天看超舒服；
* 全局排版优先使用 `Noto Sans` 思源黑体，代码块保留等宽编程字体喵！

### 5. 🛡️ 掐掉后台遥测与设备指纹

把阿里云 ARMS 行为埋点、OpenTelemetry APM 链路监控、设备指纹上报全部熔断或重定向到本地啦。人机滑块验证依然完好，不影响正常风控登录喵~


## 🐾 怎么使用喵？

环境准备：Windows x64 + Node.js (v18+)

1. **先完全退出 ZCode 客户端**喵（避免文件被占用）；
2. **双击运行 `apply_patch.bat`**（或者在控制台跑 `node auto_patch.js`）；
3. 按照提示选择提示词选项（官方订阅直接回车按 N，第三方 API 输 Y）；
4. 提示完成后，重新打开 ZCode 即可享受清爽体验啦 ٩(๑>◡<๑)۶！

想彻底还原回官方原版？随时双击运行 **`restore_backup.bat`**，原版备份秒级复原喵！
